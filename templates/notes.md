**.h** - заголовочный файл подключается в программе, в нем содержаться имена классов, функций, структур, констант. Объявляется в коде программы, например ````#include <headername.h>```.  
**.a** - файл статической библиотеки (скомпилированный бинарный файл). Внутри эьтого файла скомпилированно множество объектных файлов. Используется на этапе компиляции программы.  Код из статической библиотеки копируется в исполняемый файл, из-за чего программа может увеличиться в размере, но становиться может работать без дополнительный библиотек.  
**.so** - динамическая библиотека (shared object). Используется во время работы программы. Код программы содержит ссылки на функции в файле .so.  

**-I** - header files  
**-L** - dynamic files
