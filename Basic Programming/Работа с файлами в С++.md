Для работы с файлами нужно подключить заголовок <fstream>.  

Используемые классы:  
  - ifstream: используется для ввода.
  - ofstream: используется для вывода.
  - fstream: используется для ввода и вывода.

Прежде чем открыть файл нужно создать поток:  
```
ifstream in;
ofstream out;
fstream io;
```
После этого нужно использовать функцию open() для открытия файла:  
```
void ifstream::open(const char *имя_файла, openmode режим);
void ofstream::open(const char *имя_файла, openmode режим);
void fstream::open(const char *имя_файла, openmode режим);
```
Значения режима openmode:  
  - ios::app используется для открытия файла с целью добавления информации в его конец. Применяется только к фалйам, открытым для вывода.
  - ios::ate вызывает поиск конца файла, но операции ввода/вывода могут быть выполнены в любой части файла.
  - ios::binary двоичный режим. По умолчанию все файлы открываются в текстовом режиме.
  - ios::in, ios::out задает режим для ввода и вывода.
  - ios::trunk приводит к удалению слдержимого файла при его открытии усечению его до нулевой длины.

Пример открытия файла:  
```
ostream file;
file.open("test");
if(!file){
  cout<<"Error";
}
file.close();
```
