В языке C массив — это структура данных, содержащая фиксированный объём данных одного и того же типа. Итак, для работы с массивом нам необходимо знать его начальную позицию, размер отдельного элемента и количество элементов, которые он может содержать. Массивы представляют собой просто непрерывные области памяти, содержащие данные одного и того же типа. Всякий раз, когда вы пишете имя выделенного массива, вы фактически ссылаетесь на его адрес. Можно представить это как константное значение указателя.
```
int arr[] = {1,2,3,4,5}; // Размер массива высчитывается компилятором.  
long array1[32] = {0}; // Массив содержит 32 элемента типа long, заполнен нулями. Размер массива 256 байт.

int array2[1024]; // Объявили массив типа int на 1024 элемента.
int y = array2[64]; // Переменной y присвоили значение содержащееся в array2[64].
int first = array2[0]; // array2 фактически имеет тип int*, поскольку представляет собой указатель на первый элемент массива.  
array2[63] = 42; // Добавили значение 42 в ячейку массива array2 с индексом 63.  
```

**\*array2 == array[]**

Массивы могут быть аргументами функции:  
```
int first (int array[], size_t sz ) {
if ( sz == 0 ) return -1;
return array[0];
}
// Код выше можно записать так:  
int first (int* array, size_t sz ) {
if ( sz == 0 ) return -1;
return *array;
}
// Код выше можно соединить:
int first (int* array, size_t sz ) {
if ( sz == 0 ) return -1;
return array[0];
}
```
Порядок инициализации не имеет значений в массиве. Часто бывает удобно использовать значения перечислений или символьные значения в качестве индексов.
