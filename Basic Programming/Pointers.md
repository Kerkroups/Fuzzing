Указатель указывает на память начала данных, например массив данных или структуру и т.д.  

Наример: создадим массив целочисленных данных ```static int a[] = {11,21,31,41,51,61};```, и создадим указатель, который будет указывать на этот массив ```	int *p; p = a;```. 
Теперь *p указывает на начало массива a[], а именно на на его первый элемент a[0]. Адресс a[0] и *p совпадают. Массив a[] в нашем примере хранит тип данных int (знаковое целочисленное значение). int равен 4 байтам.
Следовательно размер массива a[] (sizeof(a)) будет равен 24 байт.  

Указатель это адрес, но этот адрес должен где-то храниться, следовательно указатель также имеет адресс ```int *p; printf("Pointer *p point to %p has an address %p\n", p, &p);```, где 
```&p``` операция взятия адресса;  
```*p``` (в правой части выражения) операция разыменования;  

Размер массива ```sizeof()``` не равен длине массива!  

Указатели на структуру:  

Указатель может указывать на структуры и функции. Например:  
```
typedef struct {
	int a;			// 4 bytes
	double b;		// 8 bytes
	int c;			// 4 bytes
	long long int d;	// 8 bytes
} MYSTRUCT;

MYSTRUCT *p,*q;
p = (MYSTRUCT*)calloc(COUNT, sizeof(MYSTRUCT));
q = p;
```
Значения указателя p и q указывают на одну область памяти (на структуру MYSTRUCT), но адреса p и q разные:  данные структуры начинаются с такого адресса 0x555555559720, но адрес указателей другой:  
```
p[0].a = 0;
p[0].b = 10000000000.0;
p[0].c = 0 * 20;
p[0].d = 4294967296;

Size of MYSTRUCT = 32
[q]
a is 0
b is 10000000000.000000
c is 0
d is 4294967296
address=0x555555559720

ADDRESS OF p = 0x7fffffffdae0
ADDRESS OF q = 0x7fffffffdad8
```

Так как указатель это адресс на начало данных, а структура это именованный набор типов данных, то мы можем реализовать массива структур.  

**ВАЖНО**: указатель != массив. Массив это сам адресс где хранятся данные, когда указатель хранит адресс где расположены данные. Указатель это переменная, массив это константа.  

```
#include <stdio.h>

int arr[] = {0,1,2,3,4,5};

void main(){
        printf("arr[2] = %d\n", arr[2]);
        printf("arr[0] address is %p\n", &arr[0]);
        printf("arr[] address is %p\n", arr);
        printf("(%p[2]) value is %d\n", arr, ((int*)0x555555558020)[2]);
}
```
Результат:  
```
arr[2] = 2
arr[0] address is 0x555555558020
arr[] address is 0x555555558020
((int*)0x555555558020)[2] value is 2
```  
Таким способом можно модифицировать данные в массиве, например: ```((int*)0x555555558020)[2] = 1```;  

При компиляции имя массива представляется как адресс в памяти, поэтому массивы это не переменная, а адресс начала данных.  

Досутп к элементам массива с использованием указателя:  
```
int data[5];
data = {1,2,3,4,5}

for(int i = 0; i < 5; i++){
	printf("%d", *(data + i));
}
```

Передача значений переменных с использованием указателей и &:  
```
void test(int *a){
	...fuction code...
}
test(&a); // Вызов функции и передача адресса переменной/указателя.  
```
