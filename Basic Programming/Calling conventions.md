**Function prologue example**:  
Во время выполнения функции rbp остаётся неизменным и указывает на начало своего стекового кадра. Локальные переменные и стековые аргументы можно адресовать относительно rbp.  
Старое значение rbp сохраняется для последующего восстановления в эпилоге. Затем устанавливается новое значение rbp, равное текущему верху стека (где, кстати, теперь хранится старое значение rbp).  
Затем в стеке выделяется память для локальных переменных путем вычитания их общего размера из rsp. Это и есть автоматическое выделение памяти в языке C, и именно этот метод мы использовали в самом первом задании для выделения буферов в стеке.

Переведено с помощью DeepL.com (бесплатная версия)
```
push rbp
mov rbp, rsp
sub rsp, 24
```

**Function epilogue example**:  
```
mov rsp, rbp
pop rbp
ret
```
OR  
```
leave
ret
```
