Структура это объединения разных типов данных в один, например:  
```
struct MYSTRUCT {
  int a;
  char b[10];
  float c;
  char *myFunc();
}
// ------------------------------------------------------------------------------------
// Более распространенный способ определить структуру.
// typedef struct {
//   int a;
//   char b[10];
//} MYSTRUCT;
// ------------------------------------------------------------------------------------
int main(){
  struct MYSTRUCT data;
  data.a = 1;
  data.b[0] = 'a';
  data.c = 1.0;
// ------------------------------------------------------------------------------------
// MYSTRUCT data;
// MYSTRUCT data = {1,'a',2.0, NULL} //Объявление структуры и задание значений переменным в соответствии с порядком типов данных в структуре.
}
```
```
typedef struct {
  int *arr;
} Data;

Data d;
d.arr = malloc(sizeof(int) * 5); // Выделим память для хранения данных 5 элементов типа int; аналогично int arr[5];
```

Доступ к элементам стрктуры осуществляется с помощью оператора ```.``` или ```->```, напрмер: ```data.a, data->a```;
