Функция - это выражение, состоящее из возвращаемого типа данных, имени и оператора вызова () в который передаются аргументы. При вызове программа передает управление коду функции, который описывается между { КОД ФУНКЦИИ }, выполняет команды в коде функции, а затем возвращается в место вызова с результатом или без него. Аргументы передаеются в функцию через запятую в строгом соответвтсии с порядком и типом, указанным при объявлении. Передача аргументов может быть по значению и указателю.  

```
int sum(int x, int y) {  // Передача аргументов по значению.
  return x + y;
}
```
Если нужно чтоб функция модифицировала исходную переменную, передают её адрес (по указателю):  
```
void increment(int *value) {
    (*value)++; // Разыменование указателя и изменение значения
}

int main() {
    int num = 10;
    increment(&num); // Передача адреса переменной с помощью оператора &
    printf("Новое значение: %d\n", num); // Выведет 11
    return 0;
}
```
**Вызов функции через указатели**:  
```
#include <stdio.h>

int multiply(int a, int b) {
    return a * b;
}

int main() {
    // Объявление указателя на функцию, принимающую два int и возвращающую int
    int (*func_ptr)(int, int) = multiply;
    
    // Вызов функции через указатель
    int result = func_ptr(4, 5);
    printf("Результат через указатель: %d\n", result);
    return 0;
}
```

**Функциональные типы**:  
В отличие от большинства типов, их нельзя объявить в качестве переменных, но в некотором смысле сами функции являются литералами этих типов. Однако можно объявлять аргументы функций, имеющие функциональные типы, которые будут автоматически преобразованы в указатели на функции.  
```
#include <stdion.h>

double g(int number){ return 0.5 + number; }
double apply(double (f)(int), int x){ return f(x); } // Можно записать как double apply(double (*f)(int), int x){...}

int main(void){
  printf("%f\n", apply(g, 10));
  return 0;
}
```
Для чего нужны эти типы? Поскольку типы указателей на функции довольно сложны для записи и чтения, их часто скрывают с помощью typedef. Неправильной (но очень распространённой) практикой является добавление звёздочки в объявлении псевдонима типа.
```
ПЛОХОЙ ПРИМЕР ОБЪЯВЛЕНИЯ
Typedef  void(*proc)(void);

ПРАВИЛЬНЫЙ ПРИМЕР ОБЪЯВЛЕНИЯ
typedef void(proc)(void);
typedef double (proc2)(int);

ПРИМЕНЕНИЕ
proc*  my_ptr  =  &some_proc;

proc2 myproc;
double myproc(int x){return 1.0 + x;}
```
