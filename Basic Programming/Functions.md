Функция - это выражение, состоящее из возвращаемого типа данных, имени и оператора вызова () в который передаются аргументы. При вызове программа передает управление коду функции, который описывается между { КОД ФУНКЦИИ }, выполняет команды в коде функции, а затем возвращается в место вызова с результатом или без него.
