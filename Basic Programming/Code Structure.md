## Declaration and definition  

**Декларация функции**: декларацию могут еще называть "прототипирование".  
```
void f(int x);
```
**Определение функции**:  
```
void f(int x){
  puts("Hi");
}
```

**Structure declaration**: часто приходится определять рекурсивные структуры данных, такие как связный список (linked list), список в котором каждый элемент хранит значение и ссылку на следующий элемент.  
```
structure list {
  int value;
  struct list* next;
}
```
Однако в случае двух взаимно рекурсивных структур необходимо добавить предварительное объявление хотя бы для одной из них.  
```
struct b;
struct a {
  int value;
  struct b* next;
}
struct b {
  struct a* other;
}
```
