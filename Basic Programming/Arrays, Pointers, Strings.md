Указатель указывает на память начала данных, например массив данных или структуру и т.д.  

Наример: создадим массив целочисленных данных ```static int a[] = {11,21,31,41,51,61};```, и создадим указатель, который будет указывать на этот массив ```	int *p; p = a;```. 
Теперь *p указывает на начало массива a[], а именно на на его первый элемент a[0]. Адресс a[0] и *p совпадают. Массив a[] в нашем примере хранит тип данных int (знаковое целочисленное значение). int равен 4 байтам.
Следовательно размер массива a[] (sizeof(a)) будет равен 24 байт.  

Указатель это адрес, но этот адрес должен где-то храниться, следовательно указатель также имеет адресс ```int *p; printf("Pointer *p point to %p has an address %p\n", *p, &p);```, где 
```&p``` операция взятия адресса;  
```*p``` (в правой части выражения) операция разыменования;  
```
int x = 10;
int *ptr = &x;  // prt содержит адрес памяти x; 
printf("X: %d\n", *ptr); // Разыменование указателя prt;
*prt = 20; // Теперь x присвоенно значение 20.
```  

Размер массива ```sizeof()``` не равен длине массива!  

Существует особый тип указателя: void*. Это указатель на данные любого типа. Язык C позволяет присваивать переменной типа void* указатели любого типа; однако эту переменную нельзя использовать в качестве объекта разыменования. Прежде чем это сделать, необходимо получить её значение и преобразовать его в допустимый тип указателя (например, int*):  
```
int a = 10;
void* pa = &a;
printf("%d\n", *((int*)pa));
```
Кроме того, вы можете передать указатель типа void* в любую функцию, которая принимает указатель на какой-либо другой тип.  

**Указатели на структуру**:  

Указатель может указывать на структуры и функции. Например:  
```
typedef struct {
	int a;			// 4 bytes
	double b;		// 8 bytes
	int c;			// 4 bytes
	long long int d;	// 8 bytes
} MYSTRUCT;

MYSTRUCT *p,*q;
p = (MYSTRUCT*)calloc(COUNT, sizeof(MYSTRUCT));
q = p;
```
Значения указателя p и q указывают на одну область памяти (на структуру MYSTRUCT), но адреса p и q разные:  данные структуры начинаются с такого адресса 0x555555559720, но адрес указателей другой:  
```
p[0].a = 0;
p[0].b = 10000000000.0;
p[0].c = 0 * 20;
p[0].d = 4294967296;

Size of MYSTRUCT = 32
[q]
a is 0
b is 10000000000.000000
c is 0
d is 4294967296
address=0x555555559720

ADDRESS OF p = 0x7fffffffdae0
ADDRESS OF q = 0x7fffffffdad8
```

Так как указатель это адресс на начало данных, а структура это именованный набор типов данных, то мы можем реализовать массива структур.  

**ВАЖНО**: указатель != массив. Массив это сам адресс где хранятся данные, когда указатель хранит адресс где расположены данные. Указатель это переменная, массив это константа.  

```
#include <stdio.h>

int arr[] = {0,1,2,3,4,5};

void main(){
        printf("arr[2] = %d\n", arr[2]);
        printf("arr[0] address is %p\n", &arr[0]);
        printf("arr[] address is %p\n", arr);
        printf("(%p[2]) value is %d\n", arr, ((int*)0x555555558020)[2]);
}
```
Результат:  
```
arr[2] = 2
arr[0] address is 0x555555558020
arr[] address is 0x555555558020
((int*)0x555555558020)[2] value is 2
```  
Таким способом можно модифицировать данные в массиве, например: ```((int*)0x555555558020)[2] = 1```;  

При компиляции имя массива представляется как адресс в памяти, поэтому массивы это не переменная, а адресс начала данных.  

Досутп к элементам массива с использованием указателя:  
```
int data[5];
data = {1,2,3,4,5}

for(int i = 0; i < 5; i++){
	printf("%d", *(data + i));
}
```

Передача значений переменных с использованием указателей и &:  
```
void test(int *a){
	...fuction code...
}
test(&a); // Вызов функции и передача адресса переменной/указателя.  
```
**Указатель на функцию**:  
Итак, функции имеют собственные адреса. Мы можем извлекать начальные адреса функций, передавать их другим функциям, вызывать функции по указателям, сохранять их в переменных или массивах и т. д. Но зачем же нам всё это делать? Это позволяет создавать более эффективные абстракции. Мы можем написать функцию, которая запускает другую функцию и измеряет время её выполнения, или преобразует массив, применяя эту функцию ко всем его элементам. Такой подход открывает совершенно новые возможности для повторного использования кода.  
Указатель на функцию хранит информацию о типе функции точно так же, как и указатели на данные. Тип функции включает в себя типы аргументов и тип возвращаемого значения. Для объявления указателя на функцию используется синтаксис, повторяющий синтаксис объявления функции:
```
<return_value_type> (*name)(arg1,arg2,...);
```
```
double doubler (int a) { return a * 2.5; }
...
double (*fptr)( int );
double a;
fptr = &doubler;
a = fptr(10); /* a = 25.0 */
```
Мы описали указатель fptr как «указатель на функцию, принимающую int и возвращающую double». Затем мы присвоили ему адрес функции doubler и выполнили вызов этой функции через данный указатель с аргументом 10, сохранив возвращаемое значение в переменной a.

Предыдущий пример можно переписать с помощью **typedef**:  
```
double doubler (int a) { return a * 2.5; }
typedef double (megapointer_type)( int );
...
double a;
megapointer_type*  variable  =  &doubler;
a  =  variable(10);  /*  a  =  25.0  */
```
C помощью `typedef` мы создали тип функции, который нельзя инициализировать напрямую. Однако мы можем создавать переменные указанного типа указателя. Поскольку переменные типа функции нельзя создавать напрямую, мы добавляем звездочку.  
Объекты первого класса в языках программирования — это сущности, которые можно передавать в качестве параметров, возвращать из функций или присваивать переменным. Как мы видим, функции в языке C не являются объектами первого класса. Иногда их называют «объектами второго класса», поскольку указатели на них являются объектами первого класса.  

**Арифметика указателей**:  

Синтаксические правила для указателей:  
1. Сложение: указатель + число;
2. Вычитание: указатель - число; указатель - указатель;
3. Арифметика указателей для типа void* запрещена;

char* = 8 байт (x64); хранит адрес символа.  
int* = 8 байт (x64); хранит адрес целочисленного.  
double* = 8 байт (x64); хранит адрес числа с плавающей точкой.  

```
int arr[] = {10, 20, 30, 40};
int *ptr = arr; // Указывает на первый элемент массива arr.
printf("Первый элемент массива arr: %d\n", *ptr); // &arr[0]
printf("Второй элемент массива arr: %d\n", *(ptr+1)); // &arr[1]
printf("Третий элемент массива arr: %d\n", *(ptr+2)); // &arr[2]

int a = 42;             /* Assume this integer's address is 1000 */
int* p_a = &a;
p_a += 42;              /* 1000 + 42 * sizeof( int ) */
p_a = p_a + 1;          /* 1168 + 1 * sizeof( int ) */
p_a --;                 /* 1172 - 1 * sizeof( int ) */

int arr[128];
int* ptr1 = &arr[50]; /* `array` address + 50 int sizes */
int* ptr2 = &arr[90]; /* `array` address + 90 int sizes */
ptrdiff_t d = ptr2 - ptr1; /* exactly 40 */
```

**Арифметика указателей для С++**:  
```
#include <iostream>
 
int main()
{
     int array [5] = { 1, 2, 3, 4 ,5 };
 
     std::cout << &array[1] << '\n'; // выведется адрес памяти элемента под индексом 1
     std::cout << array+1 << '\n'; // выведется адрес памяти указателя на массив + 1 
 
     std::cout << array[1] << '\n'; // выведется 8
     std::cout << *(array+1) << '\n'; // выведется 8 (обратите внимание на скобки, они здесь обязательны)
 
    return 0;
}
```

```array[n] == *(array+ n)```

Хорошая практика присваивать неинициализированным указателям значение NULL: ```int *ptr = NULL```;  

**Возможные ошибки связанные с указателями**:  
1. Неинициализированные указатели;
2. Разыменование нулевого указателя;
3. Утечка памяти;  
4. Переполнение буфера;

Лучшие практики:  
1. Всегда инициализировать указатель;
2. Проверять на NULL перед разыменованием;
3. Безопасно использовать выделение памяти;
4. Освобождать память после использование;

**Скрытый указатель**:  
Structure return - cкрытый указатель (sret) появился из-за ограничений процесора: регистры имею ограниченный размер, а функция может вернуть объект любого размера. Возникает вопрос, как вернуть объект большого размера, например 4096 байт? В RAX такой объект может не поместиться. Решением стало использовать такую пследвательность:  
1. Caller уже знает размер объекта.  
2. Caller выделяет память где ему удобно (на стэке, куче, внутри другого объекта).  
3. Callee заполняет выделенную память.

Маленькие структуры -> регистры;
Большие структуры -> скрытый указатель;

## Массивы и указатели  
Массивы в языке C имеют особый характер, поскольку любую группу значений, расположенных в памяти подряд, можно рассматривать как массив. Абстрактная машина считает, что имя массива — это адрес первого элемента, то есть значение указателя! i-й элемент массива можно получить с помощью одной из следующих эквивалентных конструкций:  
```
a[i] = 2;
*(a+i)  =  2
```
Адрес i-го элемента можно получить с помощью одного из следующих способов:  
```
&a[i];
a+i;
```
Как мы видим, любую операцию с указателями можно переписать с использованием синтаксиса массивов! И это ещё не всё. На самом деле синтаксис с фигурными скобками a[i] сразу преобразуется в a + i, что равносильно выражению i + a. Благодаря этому возможны и такие необычные конструкции, как 4[a] (поскольку выражение 4 + a допустимо).

Массивы можно инициализировать нулями с помощью следующего синтаксиса:  
```
int a[10] = {0};
```
Массивы имеют фиксированный размер. Однако из этого правила есть два заметных исключения, которые допускаются в C99 и более поздних версиях.
	- Массивы, выделяемые в стеке, могут иметь размер, определяемый во время выполнения. Их называют массивами переменной длины. Очевидно, что их нельзя объявить как static, поскольку это подразумевает выделение памяти в разделе .data;  
	- Начиная с C99, в качестве последнего элемента структуры можно добавить элемент типа гибкого массива;  
```
#include <string.h>
#include <malloc.h>
struct int_array {
	size_t size;
	int  array[];
};
struct int_array* array_create( size_t size ) {
	struct int_array* array = malloc(sizeof( *array ) + sizeof( int ) * size );
	array-> size = size;
	memset( array->array, 0, size );
	return array;
}
```
В данном случае оператор `sizeof`, примененный к экземпляру структуры, вернет размер структуры без учета массива. Массив будет занимать память, непосредственно следующую за экземпляром структуры. Таким образом, в приведенном выше примере `sizeof(struct char_array) == sizeof(size_t)`. Предположим, что это значение равно 8; тогда `data[0]` указывает на 8-й байт (считая от 0) от начального адреса экземпляра структуры.  

## Strings  
Любая последовательность элементов типа char, заканчивающаяся нулевым терминатором, в языке C может рассматриваться как строка. Строковый литерал - фиксированная последовательность символов, которая храниться в коде программы ("захардкожена"). Большинство строковых литералов хранятся в .rodata, если их размер достаточно велик.  

```
char* str = "when the music is over, turn out the lights";
```, где str - это указатель на первый символ строкового литерала. Согласно языковому стандарту, строковые литералы (или указатели на строки, созданные таким образом) не могут быть модифицированны. В C++ строковые литералы по умолчанию имеют тип char const*, что отражает их неизменяемый характер. Рекомендуется использовать переменные типа char const* везде, где это возможно, если строки, с которыми вы работаете, не должны изменяться.

Мы можем создать строку среди глобальных переменных. Она будет модифицируемой и ни при каких обстоятельствах не будет дублироваться в области констант.
```
char str[] = "something_global";
void f (void) { ... }
```
Другими словами, это просто глобальный массив, инициализированный на месте кодами символов.

Размещение строки в функции:
```
void func(void) {
	char str[] = "something_local";
}
```
Сама строка «something_local», однако, должна храниться где-то, поскольку локальные переменные инициализируются при каждом вызове функции, и нам необходимо знать значения, которыми их следует инициализировать. В случае относительно коротких строк компилятор попытается встроить их непосредственно в поток инструкций. Для небольших строк разумнее просто разбить их на 8-байтовые фрагменты и выполнять инструкции mov, используя каждый фрагмент в качестве непосредственного операнда. Длинные же строки лучше хранить в .rodata. Оператор, приведённый в примере выше, выделит достаточное количество байтов в стеке, а затем выполнит копирование из данных, доступных только для чтения, в этот локальный буфер стека.

Мы можем динамически выделить строку с помощью **malloc** и **memcpy** подключив заголовочный файл string.h.
```
#include <malloc.h>
#include <string.h>
int main( int argc, char** argv ) {
	char* str = (char*)malloc( 25 );
	strcpy( str, "wow, such a nice string!" );
	free( str );
}
```
