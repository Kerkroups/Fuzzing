В Си существует множество типов данных, наиболее распространенным является числовой тип данных. Важно отметить механизм явного и неявного преобрабозвания типов в Си.  
signed - числовой тип данных со знаком (-, +);  
unsigned - числовой тип данных без знака (+);  

**char** - числовой тип данных который представляет числовое значение символа в ASCII. Может быть signed и unsigned. Размер 1 байт. Варианты применения:  
```
char ch = 65; // Числовое представление символа 'A';  
char ch2 = 'A'; // Использование символьного представления;  
```
**int** - целочисленный тип данных. Может быть signed и unsigned. Может иметь различный размер:  
```
short int a; // беззнаковый, 2 байта;
signed short int a1; // знаковый, 2 байта; 
int b; // 4 байта;
long c; // В Linux 8 байт, в Windows 4 байта;
```
**float** - числовой тип данных с плавающей точкой. Размер 4 байта.  
**double** - числовой тип данных с плавающей точкой. Размер 8 байт.  
**long double** - числовой тип данных с плавающей точкой. Размер 80 бит. Стандарт С99.  

**Преобразования типов**:  
```
int a = 4;
double b = 10.5 * (double)a; // Теперь перемнная а преобразована к типу double;

int a1 = 129;
char ch = (char)a1;
printf("Character is %c, number is %d\n", ch, ch); // Character is �, number is -127. Поскольку char представляет собой (как правило) число со знаком в диапазоне от -127 до 127, число 129 не помещается в этот диапазон.

unsigned char x = 100, y = 100, z = 100;
unsigned char r = x + y + z; // Результат вычислений 300 % 256 = 44; В данном примере char unsigned и имеет размер 256.

unsigned int x = 1e9, y = 2e9, z = 3e9; // 1e9 = 1 * 10^9
unsigned int r_int = x + y + z;
unsigned long r_long = x + y + z;
printf("r_int is: %d, r_long is: %d\n", r_int, r_long); // r_int is: 1705032704, r_long is: 1705032704. Почему такие числа? Такие числа получились в результате расчета 6000000000 % (2ˆ32)

int i;
float f;
double d = f + i; // i конвертируется в float, вычисляется результат операции сложения, результат конвертируется в double, затем сохраняется в переменную d.    
```

**Сложные определения**:  
```
fp                            // Переменная;
(*fp)                         // Указатель;
(* (*fp) (int))               // Функция, принимающая int и возвращающая укаатель.
int* (* (*fp) (int)) [10]     // Функция, принимающая целое число и возвращающая указатель на массив из десяти указателей на целые числа
```
